# Atelier Nouve

Portfolio website for a fictional luxury interior design studio — built with React and Vite.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Interior photographs are loaded from [Unsplash](https://unsplash.com) under the Unsplash License for demonstration. Project names and locations are illustrative concepts, not real client commissions.
